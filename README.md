# Drapezy Fashion Ecommerce Store

Welcome to **Drapezy**, a modern and stylish ecommerce platform for fashion enthusiasts. This project delivers a seamless shopping experience, featuring curated collections for men and women, intuitive navigation, and a visually appealing interface.

## Features

- **Home Page:** Engaging hero carousel, deal of the day, new arrivals, best sellers, and customer reviews.
- **Product Catalog:** Browse by category, view all products, and filter by new arrivals or best sellers.
- **Product Details:** Detailed product pages with images, descriptions, and pricing.
- **Shopping Cart & Wishlist:** Add, remove, and manage products in your cart and wishlist.
- **Checkout Flow:** Smooth checkout process with order confirmation and order history.
- **Customer Reviews:** Swiper-based carousel for authentic customer feedback.
- **Newsletter Subscription:** Stay updated with the latest trends and offers.
- **Responsive Design:** Optimized for all devices using modern CSS and SCSS.
- **Modern UI:** Utilizes Google Fonts, Swiper.js, GSAP animations, and custom styles for a premium look and feel.

## Technologies Used

- **HTML5, CSS3, SCSS:** For structure and styling.
- **JavaScript (ES6):** For interactivity and dynamic content.
- **Swiper.js:** For carousels and sliders.
- **GSAP:** For smooth animations and scroll effects.
- **Lenis:** For smooth scrolling.
- **Google Fonts:** For modern typography.

## Getting Started

1. **Clone the repository:**
   ```sh
   git clone <your-repo-url>
   cd drapezy-fashion-ecommerce
   ```

2. **Open `index.html` in your browser** to explore the store.

3. **Customize Content:**
   - Update product data in `products.json`.
   - Add or modify images in the `images/` directory.
   - Adjust styles in `css/style.scss` and other SCSS files.

## Customization

- **Add New Products:** Update `products.json` and corresponding images.
- **Change Branding:** Replace logo and favicon in the `images/` folder.
- **Modify Styles:** Edit SCSS files in the `css/` directory for colors, fonts, and layout.
